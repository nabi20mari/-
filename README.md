# 틀린그림 탐험대

태블릿에서 바로 하는 사진 틀린그림 찾기 게임입니다. 설치할 필요가 없어요.

- `game.html`: 게임 본문 (Claude 아티팩트로 게시하는 파일)
- `index.html`: `python3 build.py`로 만든 단독 실행용 페이지 (GitHub Pages 등)
- `photos/`: 위키미디어 공용의 자유 이용 사진 (출처는 게임 안 "사진 출처 보기"에 있어요)

틀린 곳은 매 판마다 사진 위에서 자동으로 만들어집니다. 색 바꾸기, 지우기, 바꿔치기, 뒤집기, 돌리기, 크게 하기 같은 방식을 써요.
"내 사진으로 만들기"로 넣은 사진은 그 기기 안에만 저장됩니다.
